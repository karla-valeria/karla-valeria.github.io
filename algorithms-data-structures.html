CATEGORY TWO • ALGORITHMS & DATA STRUCTURES

Course
Catalog

A C++ course catalog application originally developed for my Analysis and Design coursework and expanded for my CS 499 capstone.

01 ARTIFACT

The original artifact.

I selected my ProjectTwo.cpp course catalog application for the Algorithms and Data Structures category. I originally created this project as part of my Analysis and Design coursework using C++.

The application reads course information from a file and stores the courses using an unordered map. Each course contains a course number, course title, and a list of prerequisites.

The program provides a menu that allows the user to load the course data, print the course list, and search for a specific course. When a course is selected, the program displays its title and prerequisites.

The original project provided a functional course catalog using a hash table for data storage and searching. However, it only demonstrated one primary data structure. This provided an opportunity to expand the project by implementing another data structure and comparing the approaches.

02 ENHANCEMENT

What I changed.

For my CS 499 capstone enhancement, I expanded the original course catalog by adding a binary search tree as a second data structure. The original application used an unordered map, so the enhancement allowed me to implement and evaluate a different approach to storing and searching course information.

The binary search tree uses the course number as the key for each node. I implemented functionality to insert courses into the tree, search for a specific course, and traverse the tree in order to display the course information.

I also compared the binary search tree with the original unordered map. The unordered map provides average constant-time lookup, or O(1), when the hash table performs efficiently. A binary search tree can provide O(log n) search time when the tree is reasonably balanced, although an unbalanced tree can have O(n) search time.

The enhancement required me to consider how the same course data could be organized using different data structures. This allowed me to compare their organization, searching behavior, traversal methods, and time complexity rather than relying on a single implementation.

04 COURSE OUTCOMES

Course outcomes.

This enhancement demonstrates my ability to apply algorithmic principles and data structures to a functional software application. By adding a binary search tree to the existing course catalog, I was able to apply concepts involving tree structures, searching, insertion, and traversal.

The project also demonstrates my ability to analyze different approaches to solving the same problem. The original application used an unordered map, while the enhanced version uses a binary search tree. Comparing these structures required me to consider how their organization affects searching and overall performance.

An important part of the enhancement was evaluating time complexity. The project demonstrates my understanding that different data structures can have different performance characteristics depending on how the data is organized and accessed.

05 NARRATIVE

Project reflection.

This project gave me the opportunity to revisit a program I had previously created and improve it by applying additional knowledge of algorithms and data structures. Instead of replacing the original implementation, I used it as a foundation for exploring another way to organize the same course information.

Implementing the binary search tree required me to understand how nodes are created, how values are inserted based on their keys, and how the tree can be searched and traversed. I also had to consider how the course data from the original application could be used with the new structure.

Comparing the binary search tree with the unordered map helped me better understand that choosing a data structure depends on how information needs to be stored, searched, and accessed. The project also strengthened my understanding of time complexity and the difference between average and worst-case performance.

This enhancement demonstrates my growth in C++ programming, algorithm design, data structure implementation, problem solving, and performance analysis. It also demonstrates my ability to take an existing project, identify an opportunity for improvement, and apply new technical concepts without changing the original purpose of the application.
