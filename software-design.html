CATEGORY ONE • SOFTWARE DESIGN & ENGINEERING

Event
Tracker

An Android event management application originally developed for CS 360 and expanded for my CS 499 capstone.

01 ARTIFACT

The original artifact.

I selected my Event Tracker mobile application for the Software Design and Engineering category. I originally created this application for CS 360: Mobile Architecture and Programming as an Android application using Java.

The application uses SQLite for persistent data storage and provides user account registration and login functionality. After logging in, users can access a dashboard where they can view and manage events.

The original application supports the basic CRUD operations for events. Users can create an event by entering a title, date, and location, view saved events, update event information, and delete events. The application also includes an SMS notification screen that demonstrates Android permission handling and SMS functionality.

The original project provided a functional foundation for an event management application, but its event organization, input validation, and authentication security could be expanded. These limitations provided the basis for my capstone enhancement.

02 ENHANCEMENT

What I changed.

For my CS 499 capstone enhancement, I expanded the original Event Tracker application with a focus on improving event management, input validation, and application security.

The event management system was expanded to support event categories, search and filtering options, sorting by date and time, recurring events, and customizable reminders. These features allow users to organize their events more effectively and make it easier to locate specific information as the number of events increases.

I also improved input validation so that incomplete or invalid event information cannot be saved. This makes the application more reliable and provides users with clearer feedback when information needs to be corrected.

Another major enhancement focused on authentication security. The original application stored user passwords directly in the SQLite database. I improved this design by implementing password hashing so that passwords are protected rather than stored as plain text.

These enhancements allowed me to build on an existing application rather than starting from scratch. The project required me to analyze existing code, identify areas for improvement, modify the application's logic and database structure, and add functionality while maintaining the original application's core purpose.

04 COURSE OUTCOMES

Course outcomes.

This enhancement demonstrates my ability to apply computing and algorithmic principles to an existing software application. The search, filtering, and sorting features require the application to process and organize event information based on user-selected criteria.

The project also demonstrates my ability to use Android Studio, Java, SQLite, and other development tools to expand an existing application. Rather than creating a separate project, I analyzed and modified my original CS 360 artifact to increase its functionality and value to users.

The security enhancement supports secure software development by replacing plain-text password storage with password hashing. This demonstrates my ability to identify a security weakness in existing code and apply a more secure approach to protecting user credentials.

05 NARRATIVE

Project reflection.

This project gave me the opportunity to evaluate an application I had previously developed and approach it from the perspective of a software engineer rather than simply a student completing an assignment.

Reviewing the original code helped me identify areas where the application could be made more useful, reliable, and secure. In particular, the original event management system provided only basic information and functionality, while the authentication system did not use password hashing.

Expanding the application required me to consider how new functionality would interact with the existing Java code, Android interface, and SQLite database. I also had to consider how input validation and security should be incorporated into the application rather than treated as separate features.

This enhancement demonstrates my growth in Android development, Java programming, database management, problem solving, and secure software development. It also demonstrates my ability to take an existing application, evaluate its weaknesses, and make meaningful improvements to its design and functionality.
